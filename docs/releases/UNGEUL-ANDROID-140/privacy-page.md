# 운글 Android v1.4.0 방침 준비

상태: 변경 범위 개발 검수와 독립 사실 대조 완료. 미공개이며 실제 Android SDK 검수와 앱 전체 L3 및 전 세계판 출시는 별도로 남아 있다.

사용자가 승인한 전 세계판과 분석 선택 보완의 한국어 및 영어 개인정보처리방침 갱신 범위다. 구현 후보는 `5ee13972cb87a782e9bb144b8bd72747368b848a`다.

원시 입력과 파생 풀이 요청, 선택적 프로필 저장, 운영체제 백업 및 삭제 실패를 구분했다. Android v1.4.0의 분석 선택과 설정에서 철회, GA4와 Platform 수신자, 광고 제공자의 데이터를 안내한다. 과거 구매와 계정 연결은 이용한 경우로 한정했다. Google 데이터 사용 안내의 실제 링크와 44px 이상 조작 영역을 제공한다.

타입 검사와 Svelte 진단 오류 및 경고 0개, registry 검사, Vite 빌드와 기존 67페이지 검사가 통과했다. 실제 개발 브라우저의 두 언어, 320px과 390px 및 430px, 글자100% 및200%의12조건에서 넘침0px과 링크44px 이상을 확인했다. 최초 독립 대조80항목에서 UMP 메뉴 조건2항목을 보완했고, 그2항목을 재확인하고 나머지78항목은 바이트 불변으로 이어받았다.

전체 형식 검사는 기본 브랜치와 바이트가 같은 다른 제품 파일2개의 기존 오류로 실패했다. 운글 변경 파일의 형식 검사는 통과했다. 실제 required check가 실행하는 `npm run check`와 `npm run build`는 통과했다.

실제 SDK와 기기, 서버 보관 및 삭제 운영은 미실행이다. 앱의 실제 초기 수집 중지와 업데이트 및 철회 검수를 마친 뒤 출시 범위에 맞춰 반영하고 공개 URL을 다시 확인한다.

원본 검수 자료에는 비공개 앱 소스가 포함되어 있어 비공개 앱 저장소에 보존한다. 공개 기록은 결과와 원본 manifest 해시만 담는다.
