# 루시드 리버시 데이터 보안 정정에 맞춘 개인정보처리방침

Google Play가 `com.etlegame.reversi` 버전54의 이메일 주소 데이터 보안 누락을 통보했다. 기존 공개 출시 지시 “공개 배포해야지”의 후속으로, 앱 저장소의 같은54 재제출 전에 제품별 개인정보처리방침의 한국어·영어를 실제 지원 문의와 광고 SDK 처리에 맞춘다. 기존 URL, 문서 템플릿과 언어 전환을 재사용한다. 앱의 데이터 전송 동작이나 SDK, 계정·과금 기능은 바꾸지 않는다.

설정의 지원 버튼은 `mailto:cs@seorilabs.com`을 외부 메일 앱으로 연다. 사용자가 문의하면 발신자 표시 이름, 이메일 주소와 문의 메일을 받는 경로가 있는데 기존 문구는 이름·이메일을 수집하지 않는다고 단정했다. 선택적인 문의와 회신 목적, 광고·분석 식별자와 연결하지 않는 처리를 명시한다. AdMob의 공식 Android 공개 안내와 대조해 IP 기반 대략적인 위치, 상호작용, 진단, 기기·광고 식별자를 설명한다. 외부 메일의 보안과 앱 SDK의 HTTPS/TLS도 구분한다. Google이 이메일을 관측한 정확한 네트워크 요청의 원인을 규명했다고 주장하지 않는다.

승인 범위는 현재 대화의 공개 출시 지시와 사용자에게 전달된 버전54 거절 사유를 수정해 이어 가는 작업이다. 새 개인정보 수집 기능이나 보관 기간·법적 신원을 정하는 작업이 아니다. 웹 공개 후 Google Play 선언·재심사는 `seorilabs/lucid-reversi`에서 별도로 수행한다.

문구 정정이므로 L1·dev이며 새 화면·UI 개편이 아니다. 한국어·영어 페이지를 모바일390×844와 데스크톱1440×1000에서 실제 실행해 수정일, 문의의 선택성·회신 목적, SDK 데이터4종, 언어·mailto 링크와 가로 넘침을 확인한다. `prettier --check` 대상 파일, `npm run check`, `npm run build` 및 중앙 web before-deploy를 통과한 뒤 PR로 병합한다. 공개 배포 후 두 URL의 실제 본문을 다시 읽는다. 기기 사용은 없다.

인수조건은 기존 이메일 수집 부정 문구가 사라지고 선택적 지원 문의가 두 언어에 모두 표시되는 것, AdMob 데이터 설명이 두 언어에 일치하는 것, 기존 URL·연락처·문서 탐색이 유지되는 것이다. 문구 수정이므로 구현을 복제하는 테스트를 새로 쓰지 않고 실제 빌드 문서와 실행 화면을 검사한다. 복구는 이번 콘텐츠 문구를 되돌리는 PR이며 저장 데이터에 영향이 없다.
