# Seori Labs Studio 스플래시 공개

조직 공통 v3 승인에 따라 Studio 페이지는 그림이 없고 투명한 기존 영문 심볼·워드마크를 가로와 세로 예시에 공통 사용한다. 공개 다운로드와 브랜드 안내는 동일한 SVG를 가리킨다. 공식 사이트의 공개 배포와 익명 읽기 확인까지 진행한다.

검수는 L3 개발 환경에서 Studio 페이지, 공식 브랜드 다운로드, 홈페이지 및 탐색·SEO 전체 정적 검사를 포함한다. 가로·세로 및 모바일·데스크톱의 라이트·다크 UI를 독립 검수하고, 공개된 페이지와 SVG의 해시를 빌드 결과와 대조한다.
