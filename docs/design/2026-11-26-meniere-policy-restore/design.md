# 메니에르 기록 개인정보 처리방침 복구

승인 · 버전 1 · 2026-11-26

사용자가 2026-11-26 대화에서 “원래 주소에 복구해줘.”라고 승인했다. 같은 폴더의 [테스트 계획](test-plan.json)에 따라 웹 공개까지 진행한다.

Google Play에서 Meniere Journal(`com.seoleeapps.menieresupport`)의 개인정보 처리방침을 열 수 없다는 심사 거절이 보고됐다. 심사에 적힌 링크는 `www.seorilabs.com`으로 이동한 뒤 HTTP 404를 반환한다. 끝에 슬래시를 붙인 주소와 앱 설정의 영어 주소도 404다. [공식 사이트 PR #73](https://github.com/seorilabs/seorilabs-official/pull/73)이 제품을 목록에서 내리면서 두 정책 페이지를 함께 삭제했고, 앱 설정과 Play 등록 설정에는 기존 주소가 남아 있다.

[이전에 게시한 한국어와 영어 방침](https://github.com/seorilabs/seorilabs-official/pull/54)을 원래 주소에 복구한다. 기존 사이트의 `LegalDocPage`에 두 언어의 주소를 직접 지정하고 sitemap에 두 경로를 등록한다. 복구 범위는 웹 정책 문서와 연결 정보다. 웹 정책 문서의 공개까지 이 설계에 포함하며, Google Play 재제출은 별도 승인 범위다.

문안은 앱 저장소의 `v0.1.1`과 `v0.1.2`를 기준으로 확인한다. 앱과 배포자 이름, 기기에 암호화해 저장하는 건강 기록, 사용자가 선택하는 백업과 파일 공유, Google AdMob 배너 및 동의, 보관과 삭제, 지원 연락처를 양쪽 문서에서 확인한다. 이전 공개 문안과 실제 동작에 차이가 있으면 해당 고지를 검토한다.

| 인수조건 | 검증 |
| --- | --- |
| AC-1. 한국어와 영어 경로에서 각각 해당 문서가 열린다 | L1 개발 환경에서 `npm run check`, `npm run build`와 빌드 미리보기를 실행한다. 모바일과 데스크톱 크기에서 본문, 언어 전환, 연락처, canonical과 hreflang을 확인한다. |
| AC-2. 제품 노출 상태와 분리해 정책 URL에 직접 접근할 수 있다 | 홈과 앱 목록을 확인한다. 앱 설정의 두 주소와 심사에 적힌 슬래시 없는 주소로 공개 배포 후 로그인 없이 접속해 최종 HTTP 200과 정적 HTML의 문서 제목·앱 식별자를 확인한다. |

현재 공개 URL의 404를 재현 결과로 남긴다. 기존 정적 빌드의 URL·sitemap 검사와 브라우저 실행으로 복구를 검증한다. 웹 문서와 기존 템플릿을 사용하므로 네이티브 앱 빌드와 실기기 실행은 테스트 범위에 해당하지 않는다. 배포 경로는 GitHub Pages다. 문안에 문제가 있으면 기존 주소를 유지하면서 후속 PR로 고친다.
