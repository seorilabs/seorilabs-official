# 설계: 공식 사이트 앱 목록 최신화

- 버전: 1 / 기준: 원격 main `5af8cbdcf7f166accc30b0464dd6c1d692d9371e`
- 상태: 승인. 사용자가 2026-11-10 대화에서 설계와 L1 테스트 계획을 승인했다.

## 목적과 변경 범위

공개 마켓에서 설치할 수 있는 제품을 사이트의 한국어·영어 목록에서 찾고 해당 마켓으로 이동할 수 있게 한다. 공개 여부는 제품과 채널별로 확인하며, 확인하지 못한 채널은 추가하지 않는다. 2026-11-10 Apple 한국 목록에서 판매자 Seori Labs와 다음 앱을 확인했다.

| 제품            | 현재 원장              | 변경안                    | 근거                                                         |
| --------------- | ---------------------- | ------------------------- | ------------------------------------------------------------ |
| 소금과 나침반   | 출시 예정, 채널 없음   | 서비스 중, App Store 추가 | [한국 App Store](https://apps.apple.com/kr/app/id6815764362) |
| 사이클 페어     | 출시 예정, 채널 없음   | 서비스 중, App Store 추가 | [한국 App Store](https://apps.apple.com/kr/app/id6792393652) |
| 베른할드 연대기 | 서비스 중, Google Play | App Store 추가            | [한국 App Store](https://apps.apple.com/kr/app/id6820105088) |

Google Play, 앱인토스와 다른 제품도 구현 전에 공개 목록을 대조하고 실재하는 추가 채널만 같은 원칙으로 반영한다. 확인이 안 되는 결과는 미확인으로 남긴다. 표시 이름과 소개는 해당 언어의 공개 등록정보와 대조한다. 기존 아이콘, 정책 경로, 목록 구조와 디자인은 유지한다. 새로운 화면, 앱 기능, 공개 배포는 범위 밖이다.

## 구조와 실패 처리

`src/lib/products/registry.ts`의 상태와 채널을 갱신한다. 기존 목록과 홈은 이 원장에서 파생된다. 스토어 조회가 실패하거나 지역 제한을 판별할 수 없으면 해당 채널을 추가하지 않는다. 설치 가능 국가를 확인하지 못한 경우 다른 국가에서 공개된다고 추정하지 않는다. 지속 저장 데이터, 인증, 서버 API, 외부 마켓 설정은 변경하지 않는다.

## 인수조건과 검수

| 조건                                                                       | 검증                                                 |
| -------------------------------------------------------------------------- | ---------------------------------------------------- |
| 확인된 제품이 한국어·영어 서비스 목록에 표시되고 출시 예정 목록에서 빠진다 | 개발 서버의 두 언어 목록과 홈에서 실제 브라우저 확인 |
| 각 제품의 아이콘과 기존 개인정보·계정 삭제 링크가 유지된다                 | 실제 브라우저와 경로 확인                            |
| 추가한 마켓 링크가 확인한 제품과 국가를 가리킨다                           | 브라우저에서 링크 대상과 공개 원문을 대조            |
| 기존 원장 규칙과 정적 사이트가 유효하다                                    | `npm run check`, `npm run build`                     |

정적 목록 데이터이므로 새 단위 테스트로 구현을 복제하기보다 기존 원장 검사와 공개 원문 대조, 브라우저 검수를 사용한다. L1, 개발 환경, 새 화면이나 UI 개편 없음이다. 기준 후보의 변경 파일과 기능 목록에서 검증 하한을 재확인하고 필요한 개발 환경 검수를 추가한다. 기기 접근은 계획하지 않는다. 테스트 계획은 같은 폴더의 `test-plan.json`이다.

## 적용과 복구

사람이 이 설계와 테스트 계획을 승인한 뒤 제품 원장을 변경하고 검수해 한국어 Ready PR을 만든다. PR까지만 수행하며 배포하지 않는다. 문제가 발견되면 원장 변경을 되돌린다. 배포 단계가 없으므로 운영 이관과 프로덕션 복구는 이 작업에서 수행하지 않는다.
