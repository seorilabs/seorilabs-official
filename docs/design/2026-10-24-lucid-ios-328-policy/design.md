# iOS 선택적 수집의 버전별 고지

사용자가 승인한 Lucid Chess 3.0.28 보정과 공개 범위에 맞춰 기존 한영 제품 방침을 갱신한다. iOS 3.0.28 이상에만 기본 끔과 실제 메뉴 경로를 설명하고 이전 공개 버전, Android와 앱인토스를 구분한다. 전송 중 요청과 과거 서버 자료의 삭제를 보장하지 않으며 기존 보관 및 삭제 절차는 유지한다. 기존 법무 페이지 틀의 문구 보정이며 새 화면이나 재설계는 없다.

L1에서 한영 본문과 링크, 설정 경로, 타입 및 웹 빌드를 검사하고 정상 중앙 before-deploy 검증 뒤 Pages 공개와 한영 HTTP 200 및 본문을 다시 확인한다. 기기 사용과 사용자 자료 처리는 없다.
